# Fortinet FCN FortiNAC Administrator Exam Guide

## Introduction

This repository is a study guide for learners preparing for Fortinet's FortiNAC Administrator certification. It covers network access control concepts, administration and deployment topics, practical lab suggestions, and official study resources.

## Exam Overview

**Important:** The voucher title refers to the NSE 5 FortiNAC Administrator exam. Fortinet's exam program was updated in July 2026: the NSE 5 FortiNAC-F 7.6 Administrator exam was replaced by the **NSE 6 FortiNAC 7.6 Administrator** exam.

The current Fortinet exam page describes the FortiNAC-F 7.6 Administrator exam as follows:

- **Duration:** 60 minutes
- **Questions:** 30–35
- **Scoring:** Pass or fail
- **Language:** English
- **Product versions:** FortiNAC-F 7.6 and FortiOS 7.6
- **Audience:** Network and security professionals responsible for FortiNAC configuration and administration
- **Experience:** Fortinet recommends at least six months of hands-on experience with FortiNAC-F.

Check the official exam page for current availability and details before registering.

## Who Should Take It?

This certification path is relevant to network and security professionals who work with network access control, device visibility, access policies, and FortiNAC administration.

## Main Study Areas

Use the current official exam objectives as your definitive checklist. Topics include:

### Concepts and Initial Configuration

- FortiNAC-F features and architecture
- Modeling and organizing infrastructure devices
- Network visibility and information gathering
- Logical groups and device discovery
- Isolation networks and captive networks
- Initial configuration and administrative user management

### Deployment and Provisioning

- Deployment configurations
- Device provisioning and access control
- Host discovery and management
- Troubleshooting connectivity issues
- Filters and host-page workflows
- Logging and operational monitoring

### Administration and Troubleshooting

- FortiNAC high availability (HA)
- FortiNAC Manager
- Monitoring devices and network activity
- Investigating events and alarms
- Reviewing logs and reports
- Understanding integrations with network infrastructure

## Important Concepts

Review these concepts as part of your preparation:

- Network Access Control (NAC)
- Device discovery and classification
- Host registration and visibility
- Access policies and isolation
- FortiNAC architecture and deployment modes
- Administrative roles and permissions
- High availability and centralized management
- Event monitoring, logs, and troubleshooting

## Practical Lab Ideas

Practice only in a training environment or infrastructure you are authorized to use.

1. Explore FortiNAC device discovery and inventory.
2. Create logical groups for discovered devices.
3. Review host registration and access workflows.
4. Explore isolation and captive network configurations.
5. Inspect events, alarms, and logs.
6. Practice troubleshooting a simulated host connectivity issue.
7. Review high-availability and FortiNAC Manager concepts.

## Study Strategy

1. Confirm the correct exam version and certification level.
2. Download the official exam objectives.
3. Study the FortiNAC administration and deployment documentation.
4. Pair each topic with a practical exercise where possible.
5. Use official sample questions to become familiar with question styles.
6. Review weak topics and repeat relevant lab exercises.
